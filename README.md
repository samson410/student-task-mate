TaskFlow

TaskFlow is a modern task management web application developed by SamTech. It is designed to help users organize tasks, streamline workflows, and improve productivity through a clean and intuitive interface.

📌 Project Overview

TaskFlow provides a structured way to manage daily activities, track progress, and maintain efficiency. The application focuses on simplicity, performance, and usability across different devices.

🚀 Features
Task creation and management
Responsive and clean user interface
Efficient workflow organization
Fast performance with modern tooling
Scalable and maintainable architecture
🛠️ Technologies Used
Vite
TypeScript
React
Tailwind CSS
shadcn/ui
📂 Getting Started

To run this project locally, follow these steps:

# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate into the project folder
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start development server
npm run dev
